# Archive

This folder contains historical documents that are kept for reference but are no longer part of the active project documentation.

Do not update files here. If a document in this archive becomes relevant again, move it back to the appropriate location under `docs/` and update links accordingly.

---

## Contents

### `PLAN.md`

The original 6-phase development plan written at the start of the project. Covers tickets 0–6 for the initial CLI build: schema, repositories, service layer, CLI commands, tests, and Docker/CI setup. Contains legacy references to `bible-api.com` that were superseded by the offline seed + parsers approach.

**Replaced by:** `ROADMAP.md` in the project root and `docs/PROJECT_OVERVIEW.md`.

### `BETA_DEPLOY.md`

Quick-reference card for the first Cloud Run beta deployment. Superseded by the full deployment guide.

**Replaced by:** `docs/guides/deployment.md`.

### `PR_STORY.md`

Template example for a single PR story. Superseded by the `pr_stories/` workflow.

**Replaced by:** `pr_stories/` (now also archived here).

### `pr_stories/`

PR description drafts from the development history. These capture the rationale and context for individual pull requests; they are not living documentation.

They are preserved here for audit purposes. New PR stories should be written in the root `pr_stories/` folder until that workflow changes.
